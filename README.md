# 🚀 JobTracker — MERN Stack Application

A full-stack job application tracker built with the MERN stack.

## 🌐 Live Demo
- Frontend: Coming soon
- Backend API: https://job-ma.onrender.com

## ✨ Features
- 🔐 JWT Authentication (Register/Login)
- 📋 Add, Edit, Delete Job Applications
- 📊 Status Pipeline (Applied → Interview → Offer → Rejected)
- 🔍 Search & Filter with Autocomplete
- 📱 Responsive Design with Tailwind CSS

## 🛠️ Tech Stack
| Frontend | Backend | Database |
|----------|---------|----------|
| React.js | Node.js | MongoDB Atlas |
| Tailwind CSS | Express.js | Mongoose |
| Axios | JWT Auth | bcryptjs |
| React Router | REST API | dotenv |

## 🚀 Getting Started

### Prerequisites
- Node.js
- MongoDB Atlas account

### Installation

```bash
# Clone the repo
git clone https://github.com/thuvan2004/job-ma.git

# Install frontend dependencies
cd job-tracker
npm install

# Install backend dependencies
cd server
npm install
```
